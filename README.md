# robobuddy

A virtual desktop assistant built with Python designed to automate daily tasks and fetch information quickly using web integrations and APIs.

## Features

* **Information & Search:** Queries Wikipedia, performs web searches, and pulls weather status from the Open-Meteo API.
* **Media & Web Shortcuts:** Opens popular platforms like YouTube, Google, and Stack Overflow, and handles music playback controls.
* **Desktop Automation:** Launches local applications directly (Spotify, Netflix, VS Code) and features a functional alarm utility.
* **Location Services:** Looks up nearby facilities like hospitals, restaurants, and ATMs based on location parameters.
* **Communication Support:** Includes an integrated automated email sender framework.

## How to Run It

To run this application locally on your machine, you will need [Python 3](https://python.org) installed:

1. Click the green **Code** button at the top of this GitHub page and select **Download ZIP**.
2. Extract the downloaded ZIP file on your computer.
3. Open your terminal or command prompt and navigate inside the extracted folder:
   ```bash
   cd robobuddy
   ```
4. Run the script directly using your local Python execution layout:
   ```bash
   python Robobuddy.py
   ```
